# Power BI Dashboards

Repozytorium zawiera zestaw dashboardów utworzonych w ramach nauki i doskonalenia umiejętności pracy z Power BI.  
Każdy projekt prezentuje inne zagadnienie analityczne oraz wykorzystanie różnych technik wizualizacji, modelowania danych i tworzenia miar DAX.

# Dostępne projekty

Poniżej przygotowane w ramach nauki dashboardy, każdy z własnym plikiem README.md w kolejności od najnowszego do najstarszego.


## Delegation Cost Analysis Dashboard (SQL + Power BI)

![Page1](https://github.com/piotr1ch/Delegation_Cost_-_Efficiency_Analysis/blob/main/Assets/Page1.png)

Dashboard analityczny prezentujący analizę kosztów delegacji służbowych w firmie projektowej.
Projekt został zaprojektowany w podejściu SQL-first – cała logika biznesowa, alokacja kosztów
oraz przygotowanie danych odbywają się w bazie danych, a Power BI pełni rolę warstwy analitycznej
i wizualizacyjnej.

Analiza umożliwia ocenę kosztów delegacji w czasie oraz w podziale na projekty, delegacje
i pracowników, z wykorzystaniem dziennej granularności danych.

### Zakres umiejętności

- Projektowanie relacyjnej bazy danych (MySQL)
- Normalizacja danych i relacje M:N
- Przygotowanie warstwy analitycznej w SQL
- Praca z datami i tabelą kalendarza (date_dim)
- Alokacja kosztów na pracowników i dni delegacji
- Budowa tabel faktów o dziennej granularności
- Tworzenie widoków raportowych (VIEW)
- Kontrola jakości danych w SQL
- Projektowanie modelu danych w Power BI (star schema)
- Tworzenie miar DAX (koszty, średnie, rankingi)
- Budowa dashboardu z KPI, trendami i rankingami
- Rozbudowane tooltipy kontekstowe
- Praca z Git i GitHub (struktura repozytorium, README)

[Zobacz szczegóły projektu (README.md)](https://github.com/piotr1ch/Delegation_Cost_-_Efficiency_Analysis/README.md)

[Zobacz skrypty sql)](https://github.com/piotr1ch/Delegation_Cost_-_Efficiency_Analysis/tree/main/SQL%20Scripts)


## Dividend Analysis Dashboard – Quality & Regularity

![Page1](https://github.com/piotr1ch/Analiza_dywidend/blob/main/2_Power_BI/assets/Page1.png)

Dashboard analityczny wspierający wybór spółek dywidendowych notowanych na GPW poprzez ocenę regularności wypłat oraz jakości dywidendy.
Projekt skupia się na budowie systemu scoringowego, dynamicznych rankingów oraz świadomym zarządzaniu kontekstem filtrów w DAX.

### Zakres umiejętności

- Przygotowanie i transformacja danych w Power Query
- Projektowanie modelu danych w układzie gwiazdy (star schema)
- Tworzenie zaawansowanych miar DAX (scoring, rankingi, normalizacja)
- Budowa systemu wag i agregacji wskaźników
- Dynamiczne rankingi Top N (ALLSELECTED)
- Analiza dywidend w czasie (zakres lat od–do)
- Projektowanie dashboardu wspierającego decyzje analityczne
- Scatter chart (Quality vs Regularity) z wielowymiarowym kodowaniem danych
- Rozbudowany tooltip (szczegółowa analiza spółki bez zmiany widoku)
- Praca z Git i GitHub (dokumentacja, README)

[Zobacz szczegóły projektu (README.md)](https://github.com/piotr1ch/Analiza_dywidend/blob/main/2_Power_BI/README.md)
